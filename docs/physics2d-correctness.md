# 2D 正确性修复与验收

## 比较门槛

先检查实际运动时间、穿透、稳定休眠，再比较耗时。旧的“188 倍”不作为基线：少推进时间或提前冻结的模拟不具有相同物理质量。性能比较必须使用相同场景、步长、配置、构建类型以及活动刚体数量；活动阶段和休眠阶段分别报告。

初次修复时尚未取得原始 TomCat 场景；后续已根据用户提供的路径找到原始重测程序并复测，见 [零时间碰撞后续修复](ccd-zero-time-followup.md)。下文保留初次修复的历史结果，不应当作最新结果。

## 已证实的触发链

使用修改前 HEAD 的头文件独立编译复现：

- 100 个圆同时落地：`impacts=32`，`limited=true`，一帧剩余 `0.0120661s` 被直接丢弃。远处速度为 1 的运动探针只前进约 `0.00460815`，而不是 `1/60`。再运行 180 帧，休眠数为 0。CCD 每次命中还清零已醒物体的休眠计数。
- 接触位置修正越过薄地板：小箱体中心初始 `y=0.05`，竖直速度 0；上方重箱与它的接触法线 `(0,1)`、穿透 `0.04`。地板不在最初候选接触中。修正后小箱中心 `y=-0.0189306`、底部 `y=-0.0389306`，速度仍为 0。这条穿地路径来自位置修正，而不是运动积分。
- 关节投影也有同类问题：初始 `y=0.08`、竖直速度 0，约束投影后 `y=-1`，越过薄地板。

这些证据确认了具体漏洞，但不意味着所有箱堆问题只有一个原因。

## 实现

- CCD 默认 `max_impacts=32` 保持不变，预算按运动刚体计算。同一 TOI 的命中批量处理，静态地板不再使所有落体共用一个预算。扫掠候选采用按 x 排序的空间索引；静止/纯平移形状使用紧包围盒。
- 预算耗尽、未收敛、同一碰撞对的零时间重复命中分别记录。失败只在本步剩余区间保守钳制碰撞参与者，其他物体继续接受扫掠检测。不会无检测地推进失败物体。
- 持续接触先吸收重力，再进入 CCD。多边形接触通过参考面/入射边裁剪形成最多两个接触点，带特征 ID、本地锚点、累计法向/摩擦冲量；跨帧匹配后热启动，步长改变时缩放冲量。双点法向使用耦合求解，单边接触回退到投影迭代。
- 速度求解使用本阶段缓存的流形；位置求解独立执行，用本地锚点计算新的间距与转动力臂，不在每次速度迭代重新做窄相检测。积分后重建流形。接触消失、特征/法线/锚点不匹配或销毁物体/fixture 时失效缓存。
- 接触与关节的位置修正再次检查静态/运动学障碍物。已经接触的起点使用原法线与保守角运动界限制向内投影，防止终点翻到地板另一侧后漏检。
- 接触/关节连接的动态刚体一起唤醒、一起休眠；静态地板不合并独立物体。休眠组不再执行接触冲量与位置求解。无活动双方的接触还复用流形；公开形状、变换和 fixture 偏移用精确快照比较，发生修改时重新检测。初始相切的实体也会发出 contact enter，传感器保持实际重叠语义。
- 复用 CCD 视图、约束向量、接触缓存节点；单次 broadphase 缓存包围盒；Box 包围盒和扫掠半径直接计算，不生成临时顶点数组。没有引入多线程。

## 诊断接口

`World::ccd_statistics()`：`budget_exhaustions`、`non_convergences`、`zero_time_repeats` 分别统计三类保守限制。`diagnostics` 中有原因、刚体/碰撞体索引、已推进和局部剩余时间；索引对应当次 CCD 视图顺序。`remaining_time` 表示最大局部钳制区间，**不再代表整个世界丢弃的时间**；`advanced_time` 是本次 CCD 完成的世界区间。

`World::simulation_time()` 统计已完成步长，测试同时使用独立运动探针验证实际推进，避免仅增加计时数字。

`World::on_contact_diagnostic` 可记录碰撞双方、速度、法线、穿透，以及修正前后变换。`after_integration=true` 标识积分后/速度求解前检测到的重叠；false 标识位置求解的一次修正。回调在世界锁定期间执行，不应修改物理状态。

`World::step_statistics()` 记录 CCD、检测、速度求解、位置求解毫秒数，以及约束数、实际热启动点数、位置钳制数。

## 回归与基准

```powershell
cmake -S . -B build -DBUTTER_BUILD_EXAMPLES=OFF -DBUTTER_BUILD_BENCHMARKS=ON
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure
# 可选的 25/50 层高堆；允许倒塌，逐帧检查薄地板与独立时间探针
build/tests/Release/test_2d_stability.exe --tall
# 独立运行基准，避免与构建/其他压力测试同时运行
build/benchmarks/Release/bench_2d.exe 1000 boxes
```

`test_2d_stability` 使用默认 8 次求解迭代、默认 CCD 预算，覆盖 100/500/1,000 圆落地、500/1,000 箱体单层和五层落地、五层箱堆长期静置及整组唤醒。每帧检查底部、有限坐标、时间探针；要求全部休眠。低层静置再观察 1,800 帧，检查位置/角度漂移小于 0.001、残余速度小于 0.001、层高保持。一般落地允许的数值穿透上限为 0.025，针对薄墙/位置投影的回归使用更严格的几何阈值。

`test_2d_ccd` 保留高速薄墙、旋转扫掠、动态 bullet、运动学撞击、过滤、fixture 偏移与事件测试；新增局部失败隔离、诊断分类、接触及关节位置修正越过薄地板回归。

基准先通过时间/几何/休眠门槛才输出性能。输出活动帧、活动刚体步数、完全休眠帧及各阶段耗时；额外统计普通 C++ `new/new[]` 分配次数/字节/分配耗时（不含 aligned new、释放和 C malloc）。分配耗时已包含在阶段和总耗时中，不可再次相加；计时本身有开销。TomCat 适配层耗时明确标记 unavailable，不猜测、不合成加速倍数。

## 保留边界

CCD 仍只覆盖 Circle/Box/有效凸 Polygon；Capsule/Mesh 的完整连续检测不在本次新增范围。局部钳制会损失该物体当前区间的运动，是可诊断的保守降级。CCD 尚未变成完整的动态关联组 TOI 调度器。宽相哈希表和窄相顶点临时数组仍有分配；按实测分类后继续优化，不能把休眠占比变高报告为活动求解加速。

## 本次验证结果（2026-09-21，MSVC 19.50）

- 默认预算 32、默认求解迭代 8：100/500/1,000 圆，500/1,000 单层与五层箱体均通过时间/地板/休眠门槛。单层落地无 CCD 保守限制；五层落地可能触发局部限制，仍完成实际推进并最终整组休眠。
- 25 层 500 箱体、50 层 1,000 箱体各模拟 600 帧（10 秒）：逐帧地板检查和远处运动探针通过。最小底部坐标分别约 0.0000214、0.0000122；分别有 577、577 帧局部限制，结束时均未休眠。它们仅通过“不穿地且不截断无关运动”验收，不代表高堆稳定性或活动性能已经解决。
- 原始 TomCat 场景与适配层仍需在提供其源码/配置后集成验证；这里不宣称复现了缺失的原场景。

最终标准回归：Release 14/14；Debug 13/13（大规模稳定性套件在 Release 运行，所有新增检查不依赖 assert）。CCD 可执行文件包含 118 项有效检查。

一次独立的最终基准采样（1,000 单层箱体，360 帧，全部正确性门槛通过）：

| 状态 | 帧数 | 活动刚体步数 | 总耗时 ms | CCD ms | 检测 ms | 速度求解 ms | 位置求解 ms | 普通分配次数 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 活动 | 49 | 49,000 | 471.779 | 12.764 | 398.185 | 37.749 | 4.502 | 3,802,052 |
| 全部休眠 | 311 | 0 | 1,063.170 | 21.387 | 922.352 | 8.619 | 6.478 | 8,095,918 |

这是带分配计时开销的单次观测，不是通用性能承诺。当前主要剩余开销仍是检测与临时分配，应优先继续复用空间索引、关联组构建和候选缓冲；不据此发布旧版本加速倍数。
